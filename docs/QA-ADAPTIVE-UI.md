# 问答任务自适应交互界面（第一版）

## 做的是什么

模型在现有答案生成 JSON 中增加 ui 计划，只选择组件类型和已有证据 ID。服务端验证后，从检索证据填入只读原文片段和来源链接，前端用固定 Vue 组件渲染。不是让模型编写、执行 HTML/JavaScript，也不是 OpenAI 内部实现的复刻。

可用组件：evidence（证据卡）、comparison（按主漏洞编号并排查看原文）、checklist（本地阅读核对清单）。简单问题可返回空组件列表，直接文字回答。规划并入既有生成调用，不额外调用模型，但增加少量输入/输出 token；原有最终结论复核仍保留。

## 协议

模型计划：

```json
{"version":1,"blocks":[{"type":"evidence","evidence_ids":["chunk_id"]}]}
```

计划字段固定为 version=1、blocks；每块只允许 type、evidence_ids。至多4块，各类型不能重复，每块最多5个唯一且已存在的 ID。服务端额外验证链接、注入标记和 comparison 至少2个不同主 CVE。主 CVE 只取原文开头的结构化编号，不从描述里的邻近编号猜归属。前端同样独立校验同一份 envelope（未知字段、越界、重复、非空类型、超长文本均拒绝），非法即整份回退文字回答。

SSE ui 事件：document={version:1,source:model|rules,blocks:[{id,type,items:[{id,doc_type,text,url,cve_id}]}]}。原文最多1200字符，来源 URL 仅 http(s) 且不能含认证信息。done.ui_status={status:accepted|fallback|skipped,reason}：accepted 为合法模型计划（包括空计划），fallback 为规则布局/纯文字，skipped 为拒答或筛查拦截。

## 安全与真实能力边界

- 模型只能编排，不提供新文字、评分、严重程度、修复版本、状态或可执行动作。所有证据内容由服务端绑定，组件按纯文本显示。
- 对照表是证据原文对照，不是自动算出的风险排行；同一段里提到另一个 CVE 不使证据归属改变。
- 勾选只表示用户本地阅读核对，不表示系统已经验证或完成修复，也不会触发系统命令、补采集或云端调用。
- 模型计划缺失、非法或证据门未放行时使用规则布局/文字；拒答不展示交互证据块，仍显示拒答说明。
- 本版组件以完整 ui 事件原子下发，不实现组件树增量 patch。阶段来自真实 SSE 事件，不展示模型私有思维链、不伪造进度。
- 页面保留每轮可回看快照不等于后端已经具备多轮语义；请求仍按独立问题处理。历史不自动存入浏览器持久存储。

## 验证重点

后端：未知组件/ID、HTML/动作扩展、重复及过量计划、恶意来源、邻近CVE错绑、模型规划不新增调用、规则兜底和拒答无 ui。
前端：非法协议文字回退、规则来源标识、逐轮状态隔离、取消/迟到事件、IME输入、来源筛选、核对状态、移动端和减少动效。

## 真实运行记录

- 评分类问题：模型返回 evidence 计划（1 个真实证据块），ui 事件携带服务端绑定的原文与链接，ui_status=accepted，仍是 2 次模型调用（生成+复核），无额外规划调用。
- 修复类问题：模型返回的计划不合法（未知证据编号或结构不符），回退规则 checklist，5 张卡片全部来自真实证据，含“未验证修复建议、未执行安装/扫描/PoC”的原文提示；ui_status=fallback + source=rules，前端保留卡片并标注来源。
- 模型返回空 blocks（判定文字回答更合适）：ui_status 记为 skipped（原因“模型未选择交互组件”），不显示卡片，也不宣称 accepted。
- 比较类问题证据不足：拒答、模型零调用、无 ui 事件、ui_status=skipped，符合“拒答不展示交互证据”。
- 邻近 CVE 归属：正文开头是 CVE-2021-45046、正文中提到 CVE-2021-44228 的卡片，cve_id 仍为 45046。
- 浏览器实测：对话工作区逐轮渲染、引用胶囊、真实阶段折叠、清单勾选与非执行提示、来源筛选、回到最新与新对话；一次云端瞬时降级时界面如实显示“规则兜底”。

组件不是默认答案：简单概念、空计划、拒答都保持文字。UI 只重组已有证据，不新增事实。
