## 当前环境的未验证项

本机（Windows，无 Docker / 无管理员权限 / 无 PostgreSQL 服务）无法验证：

- ⚠️ 数据库迁移与 pgvector 实际行为（便携 Postgres 因 DLL 初始化失败 `0xC0000142` 起不来）
- ⚠️ `docker compose up` 全栈
- ⚠️ 跑真实数据的 `eval/run_all.py`（三个指标的实测数值）
- ⚠️ 真实采集联调、DeepSeek 与 Ollama 兜底

**这些必须在有 Docker 的 Linux/macOS 机器上补测**，脚本里标为 `[SKIP]` 而非 `[ OK ]` 就是这个原因。
