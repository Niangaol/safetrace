# 前端动效 / 粒子 / 光线层（2026-10-06）

> 目标：让界面的“处理过程”被看见，同时保持扁平、克制、可控。**这一层是纯装饰**：不承载情报语义，不改变任何数据、证据、引用或问答结果。

## 2. 控制方式

- 全局：设置页 → 界面动效 → 完整 / 低 / 关闭（本机 `localStorage`，与模型配置无关，即时生效）。
- 系统：`prefers-reduced-motion: reduce` 时默认关闭，且 CSS 侧另有兜底，JS 未执行也不隐藏内容。
- 关闭时：不建粒子、不出帧、隐藏画布与微光；所有 CSS 动画退化为瞬时，内容完整可见。

## 3. 性能边界（都有回归兜底）

- 粒子数按视口面积估算并设上下界（默认上限 90），窄屏按 0.55 缩减，`hardwareConcurrency<=4` 再乘 0.7，低强度减半；`devicePixelRatio` 夹到 2。
- 每帧只做简单绘制（无 shadowBlur、无滤镜），每点连线数受限（默认 3），低强度不画连线和涟漪。
- 页面隐藏（`visibilitychange`）立即停帧，恢复后继续，不补偿时间跳变。
- 非法尺寸/输入被夹紧，坐标不允许 NaN（回归里对每次绘制调用做有限性断言）。

实测（本机 2070×1391、DPR 1.5、75 粒子 / 3 光束）：连续 2 秒 **180 帧 ≈ 90fps**；页面接线完成后再测（含 100 个可扫光表格行、2 个雷达面板、悬停态）仍是 **223 帧 / 2.5s ≈ 89fps**；偏好关闭后帧数归零、画布 `display:none`、粒子数 0。

## 4. 回归

`npm run smoke:effects --prefix web`（纯 node、无第三方依赖）共 12 项：偏好默认与覆盖、广播、粒子上界、长跑无 NaN、DPR 上限、强度差异、关闭不出帧、减少动效只画静态帧、隐藏暂停/恢复、连线数受限、释放安全、非法缩放夹紧。

## 5. 页面接入（真实浏览器验收）

- 工作台：情报卡入场、工位光束、悬停/键盘查看真实字段（来源、耗时、工件数、拒绝原因）。
- 看板：数字滚动终值等于原值（如 5237、0.2%、9.1），图表面板加雷达扫描与光束，表格行悬停扫光，分区标题下划线生长。
- 列表 / 详情：总数滚动、逐维可信卡悬停光斑与微升降、证据链按视口错落入场。
- 首页工作流卡：静态标题打字机 + 三卡错落入场 + 悬停光斑；移动端 390px 无横向溢出，卡片仍可点击。

验收方式：Tabbit 真实浏览器访问 127.0.0.1:5173（对接真实后端），读取 `__safetraceEffects.stats()`、绘制像素数、命中测试与帧率，并对三档动效开关逐一验证。
额外实测：发起一次真实问答后，工作台“实时”计数增加、对应工位光束点亮（station.fx-beam），历史回放不点亮；悬停“真实字段”提示框可见且层级在粒子层之上（z-index 120，含 trace_id 等真实字段）；导航当前项下划线生长为完整横线。

## 6. 语义边界（重要）

- 动效只反映**真实发生**的事情：工作台反馈由真实 SSE 事件触发，没有事件时显示“等待真实活动落纸”，不用循环动画冒充实时。
- 数字滚动的终值就是精确目标值，不使用四舍五入改变语义；检索得分、置信分照原样展示，并继续标注“不是准确率”。
- 打字机只用于静态标题/说明，不用于问答回答与证据引用（引用必须整段可读、可核对）。
- 任何纯装饰元素都带 `aria-hidden="true"`；关闭动效不影响可访问性与内容完整性。
