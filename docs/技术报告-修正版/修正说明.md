## 五、为"让指标能跑"修掉的两个 bug

这两个 bug 正是上面的数字之所以是手写的直接原因：

1. **`QAAgent.answer()` 不接受 `stream` 参数**
   `eval/qa_accuracy.py` 调 `agent.answer(q, stream=False)`，`answer` 把 `**kwargs`
   透传给无 `stream` 参数的 `answer_stream` → `TypeError`。
   **该指标从建立起从未跑通。** 已修 + `tests/test_qa_answer_kwargs.py` 钉住。
2. **`collect_latency` 只读恒为 NULL 的 `latency_seconds`**
   `published_at`/`fetched_at` 有真值却不用 → `samples: 0`、`sla_tier: "fail"`。
   已修 + `tests/test_eval_collect.py` 钉住；修后 22 条样本、档位 `excellent`。
