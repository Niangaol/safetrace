## 8. 已知限制（**不得当作"已完成"引用**）

1. **CISA KEV 全程回放**：本机 `www.cisa.gov` / `cisa.gov` DNS 解析失败，74 轮回放、窗口内条目 0。看板显示"回放中"且行不进成功轮、不进时效样本（防假绿灯）。**换机器跑或写进已知限制，待队长定**。
2. **`osv` 水位显示"回放中"= 最后一次运行的状态**：10-02 14:20Z / 10-03 01:02Z / 10-03 04:05Z / 10-04 04:39Z 各发生过 1 次单轮降级（12–23 h 一次，均为按号补抓的网络失败），其余上百轮为真实联网。**水位是"最近一轮"快照，不代表该源整体不可用**——引用时请看 `degraded_by_source` 次数。
3. **NVD 告警爆炸未修**：单轮约 10,500 条 warning 塞进 `raw.docs.parse_warnings`（同因未合并计数），影响日志体积，不影响指标。
4. **按号补抓非 404 失败时会回放固定样本**（错映射风险，请求 A 产出 B），`noFixtureFallback` 方案未合并，待队长对齐。
5. **并发读写 SQLite 偶发 `SQLITE_BUSY`**：`report.ts` 有 4 次退避重试缓解，根因（store 未开 WAL + busy_timeout）未修。
6. **无 NVD API key**：走 5 req/30s 慢速档，采集可用但吞吐受限。
7. **GitHub Actions 是否真跑过未确认**：本线路 `api.github.com` 403、GitHub HTML 不可达。
8. **前端尚未消费本组数字**：`web/src/mock.ts` 仍是假时效数，需换成 `overall.p50_seconds / p95_seconds / sla_6h_ratio`。
