# 问答最终复核与交互报告

## 本次实现

- 选定云端或本地模型生成有界引用与摘要后，再用同一个已启用模型复核草稿、检查无依据/矛盾陈述并润色。模板模式、拒答、信任或注入门禁拦截不调用复核；没有合格草稿时跳过。不会自动切换其它云端模型。
- 复核结果必须是有界 JSON，每句中文结论绑定现有证据 ID 和逐字引用；数字/CVE 必须以完整 token 出现在该句对应引用中。禁止模型 HTML 与 URL。
- 复核否定、格式错误、调用失败：丢弃草稿，不把未经复核的模型摘要显示给用户；保留逐字证据、规则结论、引用与缺口/时效提示。
- SSE done 增加 final_review {status, reason}，status 为 accepted/rejected/failed/skipped。模型真实尝试仍由 transport 回调计数；未知费用不伪造为零。
- Vue 固定 HTML/CSS 报告模板支持回答/证据折叠、Markdown/原文切换、复制错误提示、安全来源链接、移动端与减少动效。拒答和复核状态只采用 done 回执，不根据文字猜测。

## 边界

复核只处理人类阅读的模型结论摘要，不重新改写证据原文、规则推理链或引用。当前使用同一模型的第二次审阅，不是独立事实认证，更不是准确率指标。逐字证据与数字检查不能证明所有语义陈述真实。额外模型调用会增加延迟和费用；规则自然语言结论仍保留原有确定性路径。实时检索仍为 BM25，没有借此启用 dense/hybrid 或资产匹配。

## 验证

后端测试覆盖复核接受/否定/失败、逐句证据 ID/原文/数字/CVE/HTML/URL约束、拒答及不可信证据零调用。前端离线交互回归覆盖折叠、原文、剪贴板成功/失败、安全链接、所有复核状态及请求取消/迟到事件。报告回归已加入前端 build。浏览器实测拒答正确显示 abstained=true、复核跳过，并检查原文切换、折叠和390px布局。生产构建仍存在既有大包警告。

## 真实运行记录

- 真实云端模型正常应答时：一次生成加一次复核共 2 次调用，复核 accepted，输出仅由逐句绑定引用的事实组成，回执通过 SSE 下发。
- 真实运行中也出现过复核失败：云端瞬时异常时网关按既有 fallback_chain 降级为 cache 响应并带 degraded_to 标记。该响应没有事实权威性，复核门禁直接判失败并丢弃草稿；答案保留证据原文与确定性自然语言结论。这是设计的失败回退，不当成 bug 也不静默放行。
- 复核 accepted 只表示“模型自述被引用支持，且逐句引用、数字与格式约束通过”，不是独立事实认证；拒答、模板模式、安全门禁回退一律不调用复核。
