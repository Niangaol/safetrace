# 前后端交接（BigPickel → DeepSeek/全线）

> 用途：前端每次改动后，**与后端相关的部分全部写在这里**，并行 agent 改动后端时对照本
> 文件，避免「后端改了形状 / 前端旧的还在等」或「前端消费了后端没保证的字段」。
>
> 署名约定：**`web/`（前端）由 BigPickel 独占**；改后端契约/字段时，先读本文件「前端消费面」。

  要加字段先走 `contracts/schemas/CHANGELOG.md` 登记。

  卷进他人的未提交文件。

## 1. 后端目前必须对前端保证的契约

### 1.1 `/qa/chat`（SSE 流式）

前端 `QaView.vue` 消费的事件与字段（`web/src/api.ts` 解析）：

| 事件 | 前端消费点 |
| --- | --- |
| `status`/阶段事件 | 流水线步骤渲染 |
| `trace` | 检索过程可视化 |
| `citation` | 证据卡片：**必须有 `trust`、`published_at`**（未评估=null 如实标） |
| `token` | Token 成本显示 |
| `done` | 答案落盘 + 元信息面板 |

`done` 帧字段（**缺一不可，缺了前端面板缺行**）：

- `degraded` / `degraded_reason`：降级必须显式（三条工程红线之一）。
- `llm_degraded`、`elapsed_ms`、`model`、`cost_cny`、`citation_count`、`reasoning`。
- **C-04**：`stale_warning`（null 是唯一可免提示情形；有值必须展示时效风险）。
- **A-04**：`injection_guard`：
  - `screened` = **“做过筛查”**，检出危险也是 `true`；仅**无引用时为 `false`**。
  - `max_score` / `flags[]` 是**实际字段**（不是保留位）。前端有 flags 即红字告警 + 徽标。

请求体：前端 `stores/qa.ts` 的 `ask()` 现在**必带 `data_domain`**（`public|private`，
默认 `public`，与后端一致）。前端「公开域/私有域」切换只发值、不做安全承诺；
**私有域策略拒绝走 4xx 业务错误如实上屏，永不 mock**（C-05/A-03 隔离由后端强制）。

### 1.2 mock 纪律（三方红线，DeepSeek 改后端时别碰这三条）

1. 先真后假（在线失败才回退预置数据），回退必须伴随全站横幅 + 原因；
2. `VITE_USE_MOCK=false` / `never` 模式**绝不回退**；
3. **4xx 业务错误永不 mock**（包括 C-05 私有域 422 策略拒绝）——mock 层只认
   「网络/5xx」一类失败。`scripts/smoke-data-source.mjs` 6/6 守这条。

前端新增了对 `qa.answers` 两字段（stale_warning / injection_guard）的解析，
mock 层（`web/src/mock.ts`）与演示样本（`web/src/qaSample.ts`）已对齐上述语义。

### 2.11 去掉"必须拖/误触即跳转"、终端与蛛网图同高、全球地球置于标题之后、标题扫光（2026-10-01，前端-only）

改动文件：`ThreatGlobe.vue`、`TerminalWindow.vue`、`HomeView.vue`、`DetailView.vue`、`DataFlow3D.vue`。

1. **不再需要拖动，也不再误触跳转**（用户明确反馈"拖完松手/选中文字就跳走"）：
   - `ThreatGlobe` **去掉全部指针交互**（`down/move/up`、惯性、`enter` 事件、`cursor: grab`），
     `canvas` 与外层容器都设 `pointer-events: none`，从根上收不到拖动和点击；
     只保留极慢自转（`SPIN = 0.055` rad/s）+ **30fps 限帧**（原来每帧重绘，CPU 直接减半），
     pitch 固定 0.22，不再有 pitch 限幅；
   - 首页四处"整块当按钮"的点击全部下线：地球、统计卡 `.stat-item`、流转面板 `.factory-panel`、
     智能体卡 `.agent-card` —— 同时去掉 `cursor: pointer` 和 hover 位移，避免"看着能点"的错觉；
     流转面板右上角改成**真正的链接** `RouterLink /dashboard`（`.panel-go`），要跳转就点它；
   - `DataFlow3D` 同样**下线拖拽旋转**（删掉 `startDrag/onDrag/endDrag` 及拖拽状态变量，
     模板上 6 个 mousedown/mousemove/mouseup 事件一并移除），改为自动缓慢旋转；
     点节点只做"选中看详情"，不跳转；
   - 装饰性卡片补 `user-select: none`，避免划选文字时出现选区/误触。
2. **关系视图：终端与蛛网图严格同高**。根因是 `TerminalWindow` 的 `.tw { height: 100% }`
   —— 父容器高度由内容决定时，百分比高度会退化成 `auto`，终端塌回内容高度。改法：
   - 去掉 `.tw` 的 `height: 100%`，改为由父级 flex `align-items: stretch` 拉伸
     （块级布局里自然是内容高度；放大态由 `.tw.max` 的 `inset: 20px` 决定，不受影响）；
   - `.rel-term` 显式 `align-self: stretch`，`.tw-body` 继续 `flex: 1; min-height: 0` 自己滚动；
   - 窄屏纵向堆叠时给终端固定 `height: 360px`（原来 `flex: 1 1 0` 在自动高度容器里会算出 0）。
3. **地球：完整球体 + 放在标题后面 + 球体本身要"成团"**。
   - 改回**全球**（经纬网覆盖 -90°~90°，点位 Fibonacci 分布覆盖全球），不再只画北半球；
     半径 `min(w, h) / 2 * 0.97`，球心在画布中心 → 整球完整不裁切；
   - **看起来破碎**的原因：只画前半球（背面整段剔除）会在球面留下大片缺口，
     点位又用一维等分 `((i*0.618)%1)` 分布、挤成条带。改法：
     - 先铺一层极淡的球面径向渐变给出体积；
     - 经纬网**整圈都画**，背面只把透明度降到 0.06（不剔除）→ 球面连续；
       为避免逐段 `beginPath+stroke`（1600+ 次/帧）吃 CPU，改成用 `Path2D` 把
       正面段/背面段各攒成一条路径，每条网格只 `stroke()` 两次；
     - 补一条闭合轮廓圆（`rgba(148,197,255,0.34)`）勾出球外沿 —— 这一笔最能显"完整"；
     - 赤道用**真实投影 y** 单独加亮（原先对上半球写死成一条水平直线，换成全球后是错的）；
     - 点位改用标准 Fibonacci 球面分布（黄金角 137.5°、`y = 1 - 2(i+0.5)/N`），全球均匀无堆叠；
   - **自转看得见**：`SPIN` 从 0.055 提到 **0.16 rad/s**（约 39s/圈），限帧从 30fps 提到 **45fps**
     （30fps 转起来发顿，反而像"卡住不动"）；
   - 位置从"hero 底部球冠带"改为 **hero 正中、`z-index: 0`，标题/副标题/按钮 `z-index: 1`**，
     即地球在标题后面；尺寸 `clamp(280px, 42vw, 500px)`、canvas `opacity: 0.7`，
     压低存在感不喧宾夺主；hero 下边距从 344px 回到 120px；
   - 注意：系统"关闭动画"（`prefers-reduced-motion: reduce`）时按无障碍要求保持静止，
     此时看到的是一帧完整的静态球。
4. **标题扫光**。原来靠 `.ht-base` + 绝对定位的 `.ht-glow` 两层叠放实现，
   叠层一旦对不齐就看不出来。改成**单元素双背景层**：
   第 1 层是 240px 宽的亮带（`background-size: 240px 100%`），第 2 层是稳态金属渐变
   （`position: 0 0` 不动），`htSweep` 只推动第 1 层的 `background-position`
   （-300px → 900px → 1100px，6s 一轮）。这样光扫**必然**与文字严格对齐，标题也天然水平居中
   （`<h1 class="hero-title">` 单元素，`display: block; text-align: center`）。
5. 全部纯前端，无接口变更；门禁三项通过。
